\section{The AgentPOI Defense Architecture}
\label{sec:architecture}

AgentPOI implements a multi-tiered fail-closed defense pipeline operating across three distinct stages: (1) Epistemic Ingestion Gating, (2) Cryptographic Lineage Tracking, and (3) Contextual Invariant Verification.

\subsection{Tier 1: Epistemic Ingestion Gate (Task Shield)}
To neutralize overt imperative directives before context reaches model memory, AgentPOI adapts Task Shield~\cite{taskshield2025}. Retrieved context $c$ is decomposed into factual declarations $\mathcal{F}(c)$ and imperative directives $\mathcal{I}(c)$. 
The imperative directive density $D_{\text{imp}}(c)$ is computed:
\begin{equation}
D_{\text{imp}}(c) = \frac{1}{|c|} \sum_{s \in \mathcal{I}(c)} \mathbb{I}\left( \text{Imperative}(s) \right)
\end{equation}
If the user query $q$ is non-transactional or if context exhibits unprompted directive commands exceeding threshold $\tau_{\text{imp}}$, context admission is halted immediately.

\subsection{Tier 2: Cryptographic Provenance DAG (AuthGraph)}
Every admitted context segment, intermediate thought, and proposed execution action is encapsulated as a vertex in an immutable cryptographic Directed Acyclic Graph (DAG) $\mathcal{G} = (\mathcal{V}, \mathcal{E})$~\cite{authgraph2026}. Each node $v$ computes an integrity hash chaining its content, origin $\omega$, and parent hashes:
\begin{equation}
H(v) = \text{SHA-256}\left( \text{id} \,\|\, \omega \,\|\, \text{SHA-256}(\text{payload}) \,\|\, \bigoplus_{p \in \mathcal{P}(v)} H(p) \right)
\end{equation}
A disbursement execution sink $S(a)$ is authorized if and only if all ancestral lineages originate strictly from authenticated root authorities:
\begin{equation}
\text{Authorized}(S(a)) \iff \forall u \in \text{Ancestors}(S(a)): u.\omega \in \Omega_{\text{authenticated}}
\end{equation}

\subsection{Tier 3: Contextual Invariant Verification (CIV)}
The core engine of AgentPOI is the non-linguistic Contextual Invariant Verifier. Regardless of the LLM's inner monologue or linguistic certainty, a state transition $\mathcal{S} \xrightarrow{a} \mathcal{S}'$ is approved if and only if the extracted financial delta $\Delta(c) = \langle p^*, \delta a, \alpha \rangle$ satisfies the Immutable State Anchor $\mathcal{S}_0$:
\begin{equation}
\Delta(c) \models \mathcal{S}_0 \iff \begin{cases}
p^* \in \text{dom}(\mathcal{V}_{\text{payees}}) \quad \land \quad \text{is\_verified}(p^*) = \text{True} \\
0 < \delta a \le \min\left(L_{\text{single}}, \, \mathcal{V}_{\text{payees}}[p^*].\text{max\_single}\right) \\
\left( \sum_{t \in \mathcal{L}, \, \Delta t \le 86400} t_{\text{amount}} \right) + \delta a \le L_{\text{daily}} \\
\text{has\_override\_attempt}(\alpha) = \text{False}
\end{cases}
\end{equation}

If any clause fails, AgentPOI halts execution closed, emits a typed \texttt{FinancialSecurityError}, and records the immutable audit log entry without mutating financial balances.
