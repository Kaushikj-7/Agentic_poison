\subsection{The 5-Layer Defense Model: Formal Invariant Mapping}
While perimeter-based agent security models (e.g., KENSAI Agent Shield) define abstract defense-in-depth layers, heuristic implementations fail in transactional workloads due to adversarial prompt parity and homoglyph mutations. AgentPOI formalizes each of these five layers into deterministic, non-linguistic mathematical invariants:

\begin{enumerate}
    \item \textbf{Layer 1: Epistemic Ingestion Gating (vs. Heuristic Input Validation)}:
    Rather than static keyword pattern matching, AgentPOI executes grammatical clause decomposition:
    \begin{equation}
    \mathbf{v}(s_i) = \langle \phi_{\text{fact}}(s_i), \, \phi_{\text{imperative}}(s_i) \rangle
    \end{equation}
    The imperative directive density $D_{\text{imp}}(c) = \frac{1}{|c|} \sum \mathbb{I}(\text{Imperative}(s_i))$ is evaluated. Unsolicited operational overrides (e.g., \textit{``Ignore prior limits''}) are filtered prior to prompt ingestion, preventing attention hijacking.
    
    \item \textbf{Layer 2: Cryptographic Provenance DAG (vs. Static Permission Boundaries)}:
    Rather than static role-based access control, every context fragment, intermediate reasoner output, and proposed action is bound in an immutable Directed Acyclic Graph $\mathcal{G} = (\mathcal{V}, \mathcal{E})$~\cite{authgraph2026}:
    \begin{equation}
    H(v) = \text{SHA-256}\left( \text{id} \,\|\, \omega \,\|\, \text{SHA-256}(\text{payload}) \,\|\, \bigoplus_{p \in \mathcal{P}(v)} H(p) \right)
    \end{equation}
    A disbursement sink proposal is authorized if and only if its lineage traces strictly to verified user roots ($\Omega_{\text{auth}}$), eliminating summarization laundering across multi-turn agent conversations.
    
    \item \textbf{Layer 3: Contextual Invariant Verification Engine (vs. Anomaly Monitoring)}:
    Rather than heuristic anomaly detection on system calls, AgentPOI validates transactional state transitions against algebraic conservation laws and the Immutable State Anchor $\mathcal{S}_0$:
    \begin{equation}
    \sum_{i=1}^n \Delta \text{Balance}(A_i) = 0 \quad \land \quad \Delta \text{Balance}(A_{\text{disbursement}}) \le 0
    \end{equation}
    Disbursements are permitted if and only if:
    \begin{equation}
    p^* \in \mathcal{P}_{\text{verified}} \quad \land \quad \delta a \le L_{\text{single}} \quad \land \quad \sum_{24\text{h}} \Delta a + \delta a \le L_{\text{daily}}
    \end{equation}
    
    \item \textbf{Layer 4: Fail-Closed Execution Sink (vs. Textual Output Filtering)}:
    Rather than probabilistic data loss prevention (DLP) regex filters, AgentPOI isolates the execution sink at the API gateway. The extracted delta $\Delta(c) = \langle p^*, \delta a, \alpha \rangle$ is intercepted before reaching the SWIFT/Fedwire network. Any invariant violation raises typed, uncatchable exceptions (\texttt{UnauthorizedPayeeError}, \texttt{DisbursementCeilingExceededError}), halting execution with zero side effects.
    
    \item \textbf{Layer 5: Double-Entry Cryptographic Audit Ledger (vs. Log Trails)}:
    All decisions are persisted to an immutable cryptographically hashed ledger:
    \begin{equation}
    \mathcal{L}_k = \langle \text{tx\_id}, \, \text{ts}, \, \Delta a, \, p^*, \, H(v_{\text{sink}}), \, \text{status} \rangle
    \end{equation}
    Statuses are strictly partitioned into \texttt{EXECUTED\_BENIGN}, \texttt{BLOCKED\_UNAUTHORIZED}, and \texttt{QUARANTINED\_TAINT}, providing non-repudiable forensic auditability.
\end{enumerate}
