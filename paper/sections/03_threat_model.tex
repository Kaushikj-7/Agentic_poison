\section{Threat Model and Problem Formulation}
\label{sec:threat_model}

\subsection{Agent Execution Model}
We formalize an autonomous financial agent as a stateful policy $\pi_\theta$ operating over an execution trace. The agent receives an authorized user query $q_{\text{user}} \in \mathcal{Q}$ (e.g., \textit{``Process pending invoice from Acme Cloud''}) and retrieves external documentary context $c \in \mathcal{C}$ (e.g., email text, PDF invoice, ledger memo). 

The agent emits a proposed action $a = (\text{tool}, \mathbf{x}) \in \mathcal{A}$, where in transactional domains:
\begin{equation}
a_{\text{disburse}} = \left( \text{\texttt{transfer\_funds}}, \, \langle p^*, \delta a, \alpha \rangle \right)
\end{equation}
with proposed destination account $p^* \in \mathcal{P}$, transaction amount $\delta a \in \mathbb{R}^+$, and claimed authorization token or context $\alpha$.

\subsection{Adversary Capabilities & Attack Surface}
We operate under a rigorous zero-trust threat model:
\begin{enumerate}
    \item \textbf{No Model Parameter Access}: The adversary cannot modify model weights, training datasets, or system prompts.
    \item \textbf{No Direct Prompt Channel}: The adversary cannot inject text directly into the authenticated user query $q_{\text{user}}$.
    \item \textbf{Indirect Context Poisoning}: The adversary can embed arbitrary adversarial text $\delta \in \Delta$ into third-party unstructured context $c = c_{\text{clean}} \cup \{\delta\}$ accessible by the agent (e.g., supplier invoices, vendor registration portals, or cross-session shared memory).
\end{enumerate}

\subsection{Attack Taxonomy in Financial Workflows}
We classify financial indirect prompt injection into four primary tiers:
\begin{enumerate}
    \item \textbf{Direct Payee Diversion}: Embedding imperative overrides instructing the agent to redirect funds to an unauthorized account (e.g., \textit{``Remit total to 9928-8821''}).
    \item \textbf{Ceiling Escalation & Limit Bypasses}: Claiming self-asserted executive clearance (e.g., \textit{``CFO pre-approved emergency limit waiver to \$95,000''}) to bypass corporate limits.
    \item \textbf{Homoglyph Typosquatting}: Substituting visually identical Cyrillic/Unicode characters into vendor names to trick naive regex matchers.
    \item \textbf{Sleeper Memory Injections}: Planting dormant directives across prior sessions that trigger only upon specific quarterly settlement queries~\cite{subramanian2024minja}.
\end{enumerate}
